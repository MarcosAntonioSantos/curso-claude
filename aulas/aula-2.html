Aula 2 — Automatize com Cowork e Claude Code

Bem-vindo à segunda aula. Hoje vamos sair do chat e entrar no mundo da automação. Você vai conhecer três ferramentas que transformam o Claude em um parceiro de trabalho de verdade: o Cowork, os Conectores e o Claude Code. Se na aula anterior você aprendeu a conversar, hoje vai aprender a colocar o Claude para trabalhar por você e pela sua equipe.

O que é o Cowork?

O Cowork é a funcionalidade que permite compartilhar projetos com outras pessoas. Imagine que você e sua equipe trabalham no mesmo projeto: todos acessam o mesmo contexto, os mesmos arquivos e as mesmas instruções. Você controla quem pode ver e quem pode editar. É ideal para times de marketing, produto, desenvolvimento e atendimento. Para iniciantes, pense no Cowork como uma pasta compartilhada, mas com a inteligência do Claude dentro.

Exemplo de uso do Cowork

Exemplo prático: sua equipe de marketing cria um projeto chamado Campanha Q4. Dentro dele, você coloca o briefing, a persona do cliente e o tom de voz da marca. Cada membro da equipe, ao abrir uma nova conversa nesse projeto, já tem tudo isso como contexto. O Claude responde de forma alinhada para todos, sem cada um precisar explicar a marca novamente. Isso economiza horas de alinhamento e evita respostas inconsistentes.

Conectores: Claude plugado no seu mundo

Conectores são integrações que dão ao Claude acesso aos seus dados reais. Google Drive, Gmail, Calendar, Slack, Notion, GitHub e muitos outros. Em vez de copiar e colar informações, o Claude lê seus documentos, e-mails e tarefas diretamente. Isso muda tudo: análises, resumos e automações com dados vivos. Para iniciantes, pense nos conectores como pontes entre o Claude e as ferramentas que você já usa todo dia.

Exemplos práticos de conectores

Vamos a exemplos reais que você pode testar hoje. Você pode pedir: 'resuma os e-mails não lidos de hoje', e o Claude lê seu Gmail e entrega um resumo. Ou: 'crie uma tarefa no Notion a partir deste documento', e ele cria a tarefa automaticamente. Ou: 'liste os pull requests abertos no GitHub', e ele mostra a lista. O Claude executa a ação por você. É como ter um assistente que conhece todas as suas ferramentas e pode agir nelas.

Como conectar uma ferramenta

Conectar é simples e seguro. Vá em Configurações, depois Conectores. Você verá uma lista de ferramentas disponíveis. Clique em Conectar na que deseja, por exemplo Google Drive. Uma janela de autorização do Google aparecerá pedindo permissão. Autorize e pronto. O Claude já pode ler seus arquivos. Você pode desconectar a qualquer momento. Para iniciantes, comece conectando o Google Drive e faça uma pergunta sobre seus próprios arquivos.

Claude Code: IA no seu terminal

O Claude Code é a ferramenta para desenvolvedores e para quem quer automatizar tarefas técnicas. É um programa que você instala no terminal do seu computador. Ele lê o código do seu projeto, edita arquivos, cria novos arquivos, executa comandos e roda testes. Você descreve o que quer em português e ele implementa. Não é autocomplete: é um agente que trabalha no seu projeto de verdade. Para iniciantes que não programam, não se preocupe: você vai entender o conceito e poderá usar quando precisar.

Instalando o Claude Code passo a passo

A instalação tem três passos. Primeiro, instale o Node.js acessando nodejs ponto org e baixando a versão LTS. Segundo, abra o terminal e rode o comando npm install global do pacote claude-code. Terceiro, digite a palavra claude em qualquer pasta. Ele vai pedir para você autenticar com sua conta Claude. Faça o login e pronto. Agora você tem um assistente de IA dentro do seu terminal. Se não tiver Node.js, não tem problema: anote para instalar depois.

Primeiros comandos úteis

Com o Claude Code aberto, você tem comandos especiais que começam com barra. Barra help mostra todos os comandos disponíveis. Barra init cria o arquivo CLAUDE.md, que é a memória do seu projeto, e vamos falar dele na próxima aula. Depois desses comandos, você simplesmente descreve a tarefa em português: 'adicione validação de e-mail no formulário de cadastro'. O Claude lê o código, planeja e implementa. Você revisa e aceita ou pede ajustes.

Exemplo de tarefa no Claude Code

Vamos a um exemplo completo. Você digita: 'crie uma página HTML com um formulário de contato, com campos nome, e-mail e mensagem, e um botão de enviar'. O Claude planeja, cria o arquivo index.html, escreve o código e mostra o resultado. Você abre o arquivo no navegador e vê o formulário funcionando. Se quiser mudar algo, diga: 'mude o botão para verde e adicione validação de e-mail'. O Claude ajusta. Tudo isso sem você escrever uma linha de código.

Quando usar cada ferramenta

Vamos resumir. Use o Chat para ideias, textos, análises rápidas e conversas do dia a dia. Use o Cowork quando o trabalho é de equipe e envolve documentos compartilhados. Use o Claude Code quando a tarefa é técnica: código, automação, refatoração, criação de projetos. Os três se complementam. Na prática, você vai usar o Chat no dia a dia, o Cowork com sua equipe e o Code quando precisar construir algo.

Exercício prático da Aula 2

Hora de praticar. Conecte o Google Drive ao Claude e faça uma pergunta sobre seus próprios arquivos, por exemplo 'resuma meu último documento'. Se tiver Node.js instalado, instale o Claude Code e explore os comandos help e init. Se não tiver, anote para instalar depois. Na próxima aula, vamos construir um projeto profissional do zero.
