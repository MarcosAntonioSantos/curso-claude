Aula 2 — Automatize com Cowork e Claude Code

Bem-vindo à segunda aula. Hoje vamos sair do chat e entrar no mundo da automação. Você vai conhecer o Cowork, os Conectores e o Claude Code. Três ferramentas que transformam o Claude em um parceiro de trabalho de verdade.

Claude Cowork: trabalho em equipe

O Cowork permite que você compartilhe projetos com sua equipe. Todos trabalham no mesmo contexto, com os mesmos arquivos e instruções. Você controla quem pode ver e quem pode editar. É ideal para times de marketing, produto e desenvolvimento.

Conectores: Claude plugado no seu mundo

Conectores são integrações que dão ao Claude acesso aos seus dados reais. Google Drive, Gmail, Calendar, Slack, Notion, GitHub. Em vez de copiar e colar, o Claude lê seus documentos, e-mails e tarefas diretamente. Isso muda tudo: análises, resumos e automações com dados vivos.

Exemplo prático de conector

Exemplos reais: você pode pedir 'resuma os e-mails não lidos de hoje', 'crie uma tarefa no Notion a partir deste documento' ou 'liste os pull requests abertos no GitHub'. O Claude executa a ação por você. É como ter um assistente que conhece todas as suas ferramentas.

Claude Code: IA no seu terminal

O Claude Code é a ferramenta para desenvolvedores. Instalado no terminal, ele lê seu código, edita arquivos, executa comandos e roda testes. Você descreve o que quer em português e ele implementa. Não é autocomplete: é um agente que trabalha no seu projeto.

Instalando o Claude Code

A instalação é simples. Você precisa do Node.js. Depois, rode npm install global do pacote claude-code. Por fim, autentique com sua conta Claude. Pronto: digite claude em qualquer pasta e a conversa começa.

Primeiros comandos úteis

Comandos essenciais: barra help mostra tudo. Barra init cria o arquivo CLAUDE.md, que é a memória do seu projeto. Depois, basta descrever a tarefa em português: 'adicione validação de e-mail no formulário de cadastro'. O Claude lê o código, planeja e implementa.

Quando usar cada um

Resumindo: use o Chat para ideias, textos e análises rápidas. Use o Cowork quando o trabalho é de equipe e envolve documentos compartilhados. Use o Claude Code quando a tarefa é técnica: código, automação, refatoração. Os três se complementam.

Exercício prático da aula

Hora de praticar. Conecte o Google Drive ao Claude e faça uma pergunta sobre seus próprios arquivos. Se tiver Node.js, instale o Claude Code e explore os comandos help e init. Na próxima aula, vamos construir um projeto profissional do zero. Até amanhã!
