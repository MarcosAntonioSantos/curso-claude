Aula 3 — Seu projeto profissional no Claude Code

Terceira aula e a mais prática. Vamos construir um projeto profissional do zero usando o Claude Code. Do planejamento ao deploy, você vai ver o fluxo completo de um desenvolvedor que usa IA de verdade. Mesmo que você não seja desenvolvedor, vai entender como projetos são construídos e poderá acompanhar ou até liderar.

Planejamento antes do código

Antes de escrever uma linha de código, planeje. Defina o problema que seu projeto resolve. Liste as funcionalidades essenciais, o chamado MVP, ou Produto Mínimo Viável. E escolha a stack, ou seja, as tecnologias. Você não precisa saber tudo: peça ao Claude para ajudar. Digite: 'sugira a stack ideal para um app de lista de tarefas com login'. Ele vai te dar opções com prós e contras. Para iniciantes, a dica é: comece simples. Um projeto pequeno que funciona é melhor que um projeto grande que nunca fica pronto.

Exemplo de planejamento

Vamos a um exemplo concreto. Projeto: um app de lista de tarefas com login. MVP: cadastro de usuário, login, criar tarefa, editar tarefa, excluir tarefa. Stack sugerida pelo Claude: HTML, CSS e JavaScript puro, com dados salvos no localStorage do navegador. Simples, sem banco de dados, sem servidor. Perfeito para começar. Você descreve isso ao Claude Code e ele implementa passo a passo.

O que é o CLAUDE.md?

O CLAUDE.md é o arquivo mais importante do seu projeto quando você usa Claude Code. É um arquivo de texto onde você registra a stack, os padrões de código, as regras de negócio e as decisões tomadas. O Claude lê esse arquivo antes de cada ação, como um manual de onboarding para um novo desenvolvedor. A diferença é que esse onboarding é instantâneo. Sem o CLAUDE.md, o Claude pode tomar decisões inconsistentes. Com ele, o Claude trabalha alinhado com você.

Exemplo de CLAUDE.md

Veja um exemplo real. O arquivo tem seções: Stack, onde você lista as tecnologias. Padrões de código, como 'use TypeScript strict' e 'componentes funcionais'. Regras de negócio, como 'usuário precisa estar logado para criar tarefa'. Comandos úteis, como 'npm run dev' para desenvolvimento e 'npm test' para testes. E uma seção de decisões, onde você anota por que escolheu X em vez de Y. Mantenha esse arquivo atualizado. É a memória do seu projeto.

Fluxo de trabalho com Claude Code

O fluxo de trabalho tem quatro passos. Primeiro, você descreve a feature em português: 'crie a tela de login com campos e-mail e senha'. Segundo, o Claude planeja e implementa, criando ou editando arquivos. Terceiro, você revisa o diff, ou seja, as mudanças, antes de aceitar. Quarto, você faz o commit com uma mensagem clara. A regra de ouro: nunca aceite código sem ler. A IA acelera muito, mas a responsabilidade é sua. Se algo der errado, é você quem vai corrigir.

Exemplo de fluxo real

Vamos ver o fluxo na prática. Você digita: 'crie a tela de login com campos e-mail e senha e um botão Entrar'. O Claude cria os arquivos login.html e login.css e mostra o resultado. Você abre no navegador, vê a tela e decide: 'faltou validação de e-mail'. Você diz: 'adicione validação de e-mail no campo'. O Claude ajusta. Você revisa novamente, aprova e faz o commit com a mensagem 'adiciona tela de login'. Pronto. Feature implementada com revisão humana.

Testes: sua rede de segurança

Testes são sua rede de segurança. Sempre peça testes junto com o código. Digite: 'implemente a função de validar e-mail e escreva testes unitários'. O Claude Code escreve a função e os testes, roda os testes e corrige falhas automaticamente. Isso cria uma rede de segurança: mudanças futuras não quebram o que já funciona. Para iniciantes, a dica é: mesmo que você não entenda de testes, peça-os. O Claude explica o que cada teste faz.

Git e boas práticas

Use Git para versionar seu código. Crie branches por feature, ou seja, uma ramificação para cada funcionalidade nova. Faça commits pequenos e descritivos, como 'adiciona tela de login' em vez de 'mudanças'. E abra pull requests com descrição clara quando trabalhar em equipe. O Claude Code ajuda a escrever mensagens de commit e a descrever pull requests. Isso mantém o histórico limpo e facilita a revisão.

Deploy: colocando no ar

Para colocar seu projeto no ar, use plataformas como Vercel, Netlify ou Railway. Elas são gratuitas para projetos pequenos. Configure as variáveis de ambiente, como chaves de API, e ative o CI/CD, que é o deploy automático a cada push no GitHub. O Claude Code pode gerar o arquivo de configuração e o workflow do GitHub Actions. Em minutos, seu projeto está online com uma URL pública. Para iniciantes, comece com o Netlify: é o mais simples, basta arrastar a pasta do projeto.

Exercício prático da Aula 3

Prática: crie um projeto novo no seu computador, escreva o CLAUDE.md com a stack e as regras, implemente uma feature com testes usando o Claude Code e faça o commit. Se conseguir, faça o push para o GitHub e publique no Netlify. Na última aula, vamos transformar isso em renda. Até amanhã!
