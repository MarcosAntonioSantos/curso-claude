Aula 3 — Seu projeto profissional no Claude Code

Terceira aula e a mais prática. Vamos construir um projeto profissional do zero usando o Claude Code. Do planejamento ao deploy, você vai ver o fluxo completo de um desenvolvedor que usa IA de verdade.

Planejamento antes do código

Antes de escrever uma linha, planeje. Defina o problema que resolve, o escopo mínimo viável e a stack. Peça ao Claude para ajudar: 'sugira a stack ideal para um app de lista de tarefas com login'. Ele vai te dar opções com prós e contras.

O arquivo CLAUDE.md

O CLAUDE.md é a memória do projeto. Nele você registra a stack, padrões de código, regras de negócio e decisões. O Claude lê esse arquivo antes de cada ação. É como dar um manual de onboarding para um novo desenvolvedor — só que instantâneo.

Fluxo de trabalho com Claude Code

O fluxo é: você descreve a feature, o Claude planeja e implementa, você revisa o diff e aceita ou pede ajustes, depois commita. Regra de ouro: nunca aceite código sem ler. A IA acelera, mas a responsabilidade é sua.

Testes: sua rede de segurança

Peça testes junto com o código. 'Implemente a função e escreva testes unitários'. O Claude Code roda os testes e corrige falhas automaticamente. Isso cria uma rede de segurança: mudanças futuras não quebram o que já funciona.

Git e boas práticas

Use branches por feature, commits pequenos e descritivos, e pull requests com descrição clara. O Claude Code ajuda a escrever mensagens de commit e a descrever PRs. Isso mantém o histórico limpo e facilita revisão.

Deploy: colocando no ar

Para colocar no ar, use Vercel, Netlify ou Railway. Configure as variáveis de ambiente e ative o CI/CD. O Claude Code pode gerar o arquivo de configuração e o workflow do GitHub Actions. Em minutos, seu projeto está online com deploy automático a cada push.

Exercício prático da aula

Prática: crie um projeto novo, escreva o CLAUDE.md, implemente uma feature com testes e faça o commit. Se conseguir, faça o push para o GitHub. Na última aula, vamos transformar isso em renda. Até amanhã!
