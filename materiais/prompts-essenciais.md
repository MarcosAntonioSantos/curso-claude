# Prompts essenciais para usar com Claude

## Para análise
"Analise o texto abaixo e retorne: 1) resumo em 3 bullets, 2) principais riscos, 3) próximos passos. Texto: [cole aqui]"

## Para escrita
"Aja como um copywriter sênior. Escreva um e-mail de vendas para [produto], público [X], tom [Y], máximo 150 palavras."

## Para código
"Implemente a função [descrição] em [linguagem]. Inclua validação de entrada, tratamento de erros e testes unitários."

## Para planejamento
"Sugira a stack ideal para [projeto]. Compare 2 opções com prós e contras. Recomende uma."

## Para refatoração
"Refatore o código abaixo para melhorar legibilidade e performance, mantendo o comportamento. Explique as mudanças."
